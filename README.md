# Cantar360

Um painel de repertório para cantores e artistas que tocam violão.

## O que tem

- Repertório com busca, favoritos, tom e BPM, salvo no navegador.
- Modo palco com contraste alto.
- Metrônomo ajustável (40–220 BPM).
- Exercício guiado de respiração.
- Cadastro de novas músicas.

## Como usar

Abra `index.html` no navegador. Não precisa de instalação ou servidor.
